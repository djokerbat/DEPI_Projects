## 🌱 About the Project

**ToDo** is a task management web application designed to make daily planning simpler and more organized.

With a clean dashboard, task categories, priority levels, and daily progress tracking, the app brings essential planning tools together in one interface.

## ✨ Features

- &#x20;Add and edit tasks
- Organize tasks into All, Today, Upcoming, and Completed
- Highlight high-priority tasks
- Use time-based tags to organize tasks
- Search for tasks
- View daily progress
- Responsive interface for different screen sizes
